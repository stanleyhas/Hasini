# Canteen Management System

## About the Project

The Canteen Management System is a menu-driven program developed using C language.

It allows users to view the canteen menu, select food items, enter quantities, and calculate the total bill.

## Features

- Display food menu
- Select food items
- Enter quantity
- Calculate total bill
- Display final bill

## Technologies Used

- C Programming Language
- Functions
- Loops
- Conditional Statements
- Switch Case

## Objective

The objective of this project is to develop a simple C program for managing canteen orders and calculating the total bill.
